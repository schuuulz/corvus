    Installing

    Code signing is being set up, so your browser or system may warn about the installer until it is.

    • Windows: if SmartScreen says "Windows protected your PC", choose More info › Run anyway.
    • macOS: if macOS can't verify the app, open it once, then choose Open Anyway in System Settings › Privacy & Security.
    • Linux: the .AppImage updates itself; .deb and .rpm tell you when a new version is out.

    Corvus checks for updates on launch and asks before installing them.

    Corvus is open source. No telemetry, no account needed.
